# 🤖 Cute Robot Face V2 (ESP32-S3 + ST7789 + XPT2046 + MPU6500)

একটি ইন্টারেক্টিভ ও অ্যানিমেটেড রোবট ফেস প্রজেক্ট, যা **ESP32-S3 (N16R8)** মাইক্রোকন্ট্রোলারের জন্য তৈরি। এই প্রজেক্টটিতে গ্রাফিক্সের ফ্লিগার (Flicker বা কাপুনি) দূর করার জন্য অত্যন্ত চমৎকারভাবে ফ্রেম বাফার ব্যবহার করা হয়েছে, যার ফলে রোবটের চোখ এবং এক্সপ্রেশনগুলো দারুণ স্মুথভাবে নড়াচড়া করে। নতুনরা খুব সহজেই যেন এটি তৈরি করতে পারে, তার সম্পূর্ণ গাইডলাইন নিচে দেওয়া হলো।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)
* **স্মুথ ও ফ্লিগার-মুক্ত অ্যানিমেশন:** অফ-স্ক্রিন ফ্রেম বাফার ব্যবহারের কারণে স্ক্রিনে কোনো ধরনের ল্যাগ বা কাপুনি ছাড়াই অ্যানিমেশন দেখা যায়।
* **একাধিক এক্সপ্রেশন (Expressions):** রোবটটি বিভিন্ন সময় আইডিএল (IDLE), হ্যাপি (HAPPY), লাভ (LOVE), কিউরিয়াস (CURIOUS), স্লিপি (SLEEPY), অ্যাংরি (ANGRY) এবং সারপ্রাইজড (SURPRISE)—এই ৭টি ভিন্ন মুড বা এক্সপ্রেশন দেখাতে পারে।
* **জাইরোস্কোপিক গেজ (Gyro Gaze):** MPU6500 সেন্সর থাকার কারণে আপনি বোর্ডটি যেদিকে কাত (Tilt) করবেন, রোবটের চোখও সেদিকে তাকাবে।
* **টাচ কন্ট্রোল:** ডিসপ্লেতে টাচ করে এক্সপ্রেশন পরিবর্তন করা যায় এবং পরপর ৫টি দ্রুত ট্যাপ করলে রোবট রেগে (ANGRY) যায়।
* **বিল্ট-ইন টিউনিং মেনু:** বোর্ডটি উল্টো করে ৩ সেকেন্ড ধরে রাখলে একটি টিউনিং মেনু ওপেন হবে, যেখান থেকে সেন্সিভিটি কনফিগার করা সম্ভব।

## 🛠️ প্রয়োজনীয় হার্ডওয়্যার (Hardware Requirements)
1. ESP32-S3 (N16R8) ডেভেলপমেন্ট বোর্ড
2. ST7789 2.4-inch TFT Display (240x320) উইথ XPT2046 টাচ কন্ট্রোলার
3. MPU6500 অথবা MPU6050 জাইরো/অ্যাক্সিলোমিটার সেন্সর
4. কানেক্টিং ওয়্যার ও ব্রেডবোর্ড

## 🔌 পিন টু পিন কানেকশন ডায়াগ্রাম (Wiring Guide)

নতুনদের সুবিধার জন্য পিন কানেকশনগুলো নিচে টেবিল আকারে দেওয়া হলো:

### ১. TFT ডিসপ্লে এবং টাচ পিন কানেকশন
| TFT / Touch Pin | ESP32-S3 Pin | কাজ (Description) |
| :--- | :--- | :--- |
| **SCK / SCLK** | GPIO 13 | SPI Clock |
| **MISO / T_DO** | GPIO 12 | SPI MISO |
| **MOSI / T_DIN** | GPIO 11 | SPI MOSI |
| **CS** | GPIO 10 | Chip Select (Display) |
| **DC** | GPIO 9 | Data/Command |
| **RST** | GPIO 8 | Reset |
| **LED** | GPIO 5 | Backlight (শক্তির জন্য) |
| **TOUCH_CS** | GPIO 7 | Touch Chip Select |

### ২. MPU6500 / MPU6050 সেন্সর কানেকশন
| MPU Sensor Pin | ESP32-S3 Pin | কাজ (Description) |
| :--- | :--- | :--- |
| **VCC** | 3.3V | পাওয়ার সাপ্লাই |
| **GND** | GND | গ্রাউন্ড |
| **SDA** | GPIO 16 | I2C Data |
| **SCL** | GPIO 15 | I2C Clock |

2. **Adafruit ST7789 Library**
3. **XPT2046_Touchscreen**

## 🚀 কোড আপলোড এবং ব্যবহারবিধি
1. Arduino IDE ওপেন করুন এবং ওপরের লাইব্রেরিগুলো ইনস্টল করা নিশ্চিত করুন।
2. আপনার হার্ডওয়্যার কানেকশন টেবিল অনুযায়ী সঠিকভাবে মিলিয়ে নিন।
3. প্রজেক্টের মেইন কোডটি (যেমন: `CuteRoboFace.ino`) Arduino IDE-তে ওপেন করুন।
4. বোর্ড হিসেবে **ESP32S3 Dev Module** সিলেক্ট করে সঠিক পোর্ট সিলেক্ট করুন এবং আপলোড বাটনে ক্লিক করুন।
5. **বুট বাটন (BOOT Button):** বোর্ডের অনবোর্ড BOOT বাটন চাপলে রোবট ভয় পাওয়ার (FEAR) রিঅ্যাকশন দেখাবে।
6. স্ক্রিনে টাচ করে অথবা বোর্ড নড়াচড়া করিয়ে রোবটের ইন্টারঅ্যাকশন উপভোগ করুন!
