# 🤖 Cute Robot Face V2 (ESP32 / ESP32-S3 + ST7789 + XPT2046 + MPU6500)

একটি অত্যন্ত আকর্ষণীয় ও স্মুথ অ্যানিমেটেড রোবট ফেস প্রজেক্ট, যা **ESP32** এবং **ESP32-S3 (N16R8)** মাইক্রোকন্ট্রোলারের সাহায্যে তৈরি করা যায়। গ্রাফিক্সের ফ্লিকার (Flicker বা কাপুনি) দূর করার জন্য এতে চমৎকার ফ্রেম বাফার টেকনিক ব্যবহার করা হয়েছে, যার ফলে রোবটের চোখ এবং এক্সপ্রেশনগুলো দারুণ সাবলীলভাবে নড়াচড়া করে। নতুনরা খুব সহজেই যেন এটি তৈরি করতে পারে, তার সম্পূর্ণ ও গোছানো গাইডলাইন নিচে দেওয়া হলো।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)
* **ফ্লিকার-মুক্ত স্মুথ অ্যানিমেশন:** অফ-স্ক্রিন ফ্রেম বাফার ব্যবহারের কারণে স্ক্রিনে কোনো ধরনের ল্যাগ বা কাপুনি ছাড়াই নিখুঁত অ্যানিমেশন দেখা যায়।
* **একাধিক এক্সপ্রেশন (Expressions):** রোবটটি আইডিএল (IDLE), হ্যাপি (HAPPY), লাভ (LOVE), কিউরিয়াস (CURIOUS), স্লিপি (SLEEPY), অ্যাংরি (ANGRY) এবং সারপ্রাইজড (SURPRISE)—এই ৭টি ভিন্ন মুড দেখাতে পারে।
* **জাইরোস্কোপিক গেজ (Gyro Gaze):** MPU6500 সেন্সর থাকার কারণে আপনি বোর্ডটি যেদিকে কাত (Tilt) করবেন, রোবটের চোখও সেদিকে তাকাবে।
* **টাচ কন্ট্রোল:** ডিসপ্লেতে টাচ করে এক্সপ্রেশন পরিবর্তন করা যায় এবং পরপর ৫টি দ্রুত ট্যাপ করলে রোবট রেগে (ANGRY) যায়।
* **বিল্ট-ইন টিউনিং মেনু:** বোর্ডটি উল্টো করে ৩ সেকেন্ড ধরে রাখলে টিউনিং মেনু ওপেন হবে, যেখান থেকে সেন্সিভিটি কনফিগার করা সম্ভব।

## 🛠️ প্রয়োজনীয় হার্ডওয়্যার (Hardware Requirements)
1. ESP32 অথবা ESP32-S3 (N16R8) ডেভেলপমেন্ট বোর্ড
2. ST7789 2.4-inch TFT Display (240x320) উইথ XPT2046 টাচ কন্ট্রোলার
3. MPU6500 অথবা MPU6050 জাইরো/অ্যাক্সিলোমিটার সেন্সর
4. কানেক্টিং ওয়্যার ও ব্রেডবোর্ড

## 🔌 পিন টু পিন কানেকশন ডায়াগ্রাম (Wiring Guide)

নতুনদের সুবিধার জন্য **ESP32-S3** এবং সাধারণ **ESP32** বোর্ডের পিন কানেকশনগুলো আলাদাভাবে নিচে টেবিল আকারে দেওয়া হলো:

### ১. TFT ডিসপ্লে এবং টাচ পিন কানেকশন
| TFT / Touch Pin | ESP32-S3 Pin | ESP32 (DevKit V1) Pin | কাজ (Description) |
| :--- | :--- | :--- | :--- |
| **SCK / SCLK** | GPIO 13 | GPIO 18 | SPI Clock |
| **MISO / T_DO** | GPIO 12 | GPIO 19 | SPI MISO |
| **MOSI / T_DIN** | GPIO 11 | GPIO 23 | SPI MOSI |
| **CS** | GPIO 10 | GPIO 15 | Chip Select (Display) |
| **DC** | GPIO 9 | GPIO 2 | Data/Command |
| **RST** | GPIO 8 | GPIO 4 | Reset |
| **LED** | GPIO 5 | 3.3V / GPIO 23 | Backlight (শক্তির জন্য) |
| **TOUCH_CS** | GPIO 7 | GPIO 22 | Touch Chip Select |

### ২. MPU6500 / MPU6050 সেন্সর কানেকশন
| MPU Sensor Pin | ESP32-S3 Pin | ESP32 (DevKit V1) Pin | কাজ (Description) |
| :--- | :--- | :--- | :--- |
| **VCC** | 3.3V | 3.3V | পাওয়ার সাপ্লাই |
| **GND** | GND | GND | গ্রাউন্ড |
| **SDA** | GPIO 16 | GPIO 21 | I2C Data |
| **SCL** | GPIO 15 | GPIO 22 | I2C Clock |

## 📦 প্রয়োজনীয় লাইব্রেরি ইনস্টলেশন (Software Prerequisites)
Arduino IDE ব্যবহার করে কোডটি আপলোড করার আগে লাইব্রেরি ম্যানেজার থেকে নিচের লাইব্রেরিগুলো ইনস্টল করে নিতে হবে:
1. **Adafruit GFX Library**
2. **Adafruit ST7789 Library**
3. **XPT2046_Touchscreen**

---

## 🚀 কোড আপলোড এবং ব্যবহারবিধি
1. Arduino IDE ওপেন করুন এবং ওপরের লাইব্রেরিগুলো ইনস্টল করা নিশ্চিত করুন।
2. আপনার ব্যবহৃত বোর্ড অনুযায়ী সঠিক হার্ডওয়্যার কানেকশন মিলিয়ে নিন।
3. প্রজেক্টের মেইন কোডটি Arduino IDE-তে ওপেন করুন।
4. বোর্ড হিসেবে আপনার কাঙ্ক্ষিত বোর্ড (যেমন: *ESP32S3 Dev Module* অথবা *ESP32 Dev Module*) সিলেক্ট করে সঠিক পোর্ট দিয়ে কোড আপলোড করুন।
5. **বুট বাটন (BOOT Button):** বোর্ডের অনবোর্ড BOOT বাটন চাপলে রোবট ভয় পাওয়ার (FEAR) রিঅ্যাকশন দেখাবে।
6. স্ক্রিনে টাচ করে অথবা বোর্ড নড়াচড়া করিয়ে রোবটের দারুণ সব ইন্টারঅ্যাকশন উপভোগ করুন!
